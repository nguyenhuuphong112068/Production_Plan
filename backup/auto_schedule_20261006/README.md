# Backup code sắp lịch tự động — 06/10/2026

Bản sao các file liên quan tới "Sắp lịch tự động" TRƯỚC khi thêm plugin Kiểm soát tồn BTP
(app/Plugins/WipControl). Bao gồm cả các thay đổi chưa commit tại thời điểm backup.

Muốn quay lại: so sánh / chép đè file tương ứng từ thư mục này về đúng đường dẫn gốc.
Tắt plugin mà không cần chép đè: bỏ dòng WipControlServiceProvider trong bootstrap/providers.php.
